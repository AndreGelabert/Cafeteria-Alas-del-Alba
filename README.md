# Cafeteria Alas del Alba

Bem-vindo ao repositório da **Cafeteria Alas del Alba**, uma landing page desenvolvida para apresentar a essência de uma cafeteria acolhedora, moderna e convidativa.

## Sobre o projeto

Este projeto foi criado como uma página de apresentação para destacar a identidade visual da cafeteria, seus produtos, ambiente e proposta de valor.  
A landing page tem como objetivo oferecer uma experiência simples, bonita e responsiva para os visitantes.

## Funcionalidades

- Design moderno e atrativo
- Estrutura responsiva para diferentes tamanhos de tela
- Seções de apresentação da cafeteria
- Ênfase em experiência visual e navegação intuitiva
- Projeto feito com **HTML** e **JavaScript**

## Tecnologias utilizadas

- HTML
- JavaScript

## Estrutura do projeto

A estrutura pode variar conforme a implementação, mas normalmente inclui:

- `index.html` — página principal
- `site.js` — lógica e interações da landing page
- Arquivos de mídia e estilos adicionais, se aplicáveis
